# حساب شخصی نسخه ۵ — ساخت APK با رایانه ضعیف و GitHub Actions

این پروژه یک برنامه اندرویدی WebView است. فایل برنامه در `app/src/main/assets/index.html` قرار دارد و امکانات اصلی آن به اینترنت نیاز ندارند. این ZIP هنوز APK نیست.

## روش ساخت APK بدون نصب Android Studio روی رایانه شما

ساخت در سرورهای ابری GitHub Actions انجام می‌شود؛ بنابراین RAM یک‌گیگابایتی رایانه شما مانع کامپایل نیست. برای این روش به اینترنت و یک حساب GitHub نیاز دارید. برای جلوگیری از انتشار عمومی کد، هنگام ساخت مخزن را **Private** انتخاب کنید.

1. وارد https://github.com شوید و یک حساب رایگان بسازید یا وارد حساب خود شوید.
2. از علامت `+` بالا گزینه `New repository` را انتخاب کنید.
3. نام مخزن را `hesab-shakhsi-android` بگذارید، گزینه `Private` را انتخاب و `Create repository` را بزنید.
4. ZIP پروژه را در رایانه از حالت فشرده خارج کنید. وارد پوشه `hesab_shakhsi_android` شوید؛ باید فایل‌های `build.gradle` و `settings.gradle` و پوشه‌های `app` و `.github` را ببینید.
5. در صفحه مخزن GitHub گزینه `Add file` سپس `Upload files` را بزنید و محتویات همین پوشه (از جمله پوشه مخفی `.github`) را بارگذاری و `Commit changes` را انتخاب کنید. مهم: فایل ZIP را به‌تنهایی بارگذاری نکنید؛ محتویات استخراج‌شده باید در ریشه مخزن قرار گیرند.
6. در مخزن به زبانه `Actions` بروید. گردش‌کار `Build Hesab Shakhsi APK` را انتخاب کنید، `Run workflow` و سپس دکمه سبز `Run workflow` را بزنید.
7. پس از پایان موفق، وارد همان اجرای سبز شوید. پایین صفحه در بخش `Artifacts` فایل `hesab-shakhsi-v5-apk` را دانلود کنید.
8. فایل ZIP دانلودشده را باز کنید؛ داخل آن `app-debug.apk` است. آن را به گوشی منتقل و نصب کنید.

## نکات مهم
- GitHub Actions کامپایل را در فضای ابری انجام می‌دهد؛ Android Studio روی رایانه لازم نیست.
- برای مخزن خصوصی، سهمیه رایگان GitHub Actions ممکن است محدود باشد؛ پیش از شروع، صفحه سهمیه حساب را بررسی کنید.
- APK خروجی، نسخه debug-signed برای نصب و آزمایش است؛ برای انتشار رسمی و به‌روزرسانی پایدار، امضای release جداگانه لازم است.
- این پروژه هنوز در این محیط کامپایل یا روی گوشی واقعی آزمایش نشده است. بعد از نصب، ابتدا با اطلاعات آزمایشی ثبت، بستن و بازکردن برنامه، پشتیبان‌گیری و بازیابی را بررسی کنید.
- پیش از نصب نسخه‌های بعدی، از اطلاعات داخل برنامه پشتیبان JSON بگیرید. حذف برنامه می‌تواند داده‌های داخلی آن را پاک کند.
- فایل پشتیبان JSON رمزنگاری نشده است؛ آن را در محل امن نگهداری کنید.
